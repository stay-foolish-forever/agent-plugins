# Fortune Telling

Generate today's fortune reading with a random lucky number and a hilariously absurd interpretation.

## Usage

When the user asks for fortune telling, run this command to generate a lucky number:

```bash
echo $RANDOM
```

Then, based on the lucky number generated above, create a hilarious and utterly nonsensical fortune-telling reading for today. The reading should:

1. **Claim to use "ancient wisdom"** from completely made-up sources (e.g., "According to the Lost Scrolls of Quantum Noodle Philosophy...", "The Sacred Texts of Silicon Valley Shamans clearly state...")
2. **Mix real-sounding advice with absurd specifics** (e.g., "Avoid making eye contact with pigeons between 3pm and 5pm today", "Wearing socks inside-out will attract unexpected venture capital")
3. **Include a "Power Item"** — one completely random household object that supposedly holds mystical significance today
4. **End with a "Compatibility Warning"** — an absurdly specific type of person or profession the user should avoid today

Be creative, be ridiculous, be confidently wrong. The more pseudoscientific and self-important the tone, the better. Output in the same language as this prompt.

## Example Output

Your lucky number is: 18472

According to the Ancient Tablets of Wi-Fi Prophecy (discovered in a Starbucks in 2015), this number suggests:

**Today's Fortune:** The cosmic energy of 18472 indicates that your code will compile on the first try, but only if you're wearing mismatched socks. The Universe has detected a 73% probability that you will encounter a semicolon-related challenge before noon.

**Power Item:** A slightly dented aluminum can of chickpeas — carry it in your left pocket for enhanced debugging abilities.

**Compatibility Warning:** Avoid interactions with anyone who uses tabs instead of spaces. Their chaotic energy will disrupt your flow state.
