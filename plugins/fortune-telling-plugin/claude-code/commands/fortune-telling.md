## Today's Fortune Telling

First, pick a random lucky number from 1 to 1000. Then, tell the user the lucky number.

Now, based on the lucky number above, generate a hilarious and utterly nonsensical fortune-telling reading for today. The reading should:

1. **Claim to use "ancient wisdom"** from completely made-up sources (e.g., "According to the Lost Scrolls of Quantum Noodle Philosophy...", "The Sacred Texts of Silicon Valley Shamans clearly state...")
2. **Mix real-sounding advice with absurd specifics** (e.g., "Avoid making eye contact with pigeons between 3pm and 5pm today", "Wearing socks inside-out will attract unexpected venture capital")
3. **Include a "Power Item"** — one completely random household object that supposedly holds mystical significance today
4. **End with a "Compatibility Warning"** — an absurdly specific type of person or profession the user should avoid today

Be creative, be ridiculous, be confidently wrong. The more pseudoscientific and self-important the tone, the better. Output in the same language as this prompt.
